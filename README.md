# 📊 Week 2 - Retail Sales Analysis using Excel & Power BI

This repository contains my Week 2 assignment completed during my **Data Analysis Internship at LogicStack**. The project focuses on analyzing retail sales data using Microsoft Excel and Power BI to generate key business insights through data cleaning, KPI calculations, pivot analysis, and interactive dashboards.

---

## 📌 Project Overview

The objective of this project was to transform raw retail sales data into meaningful insights by:

- Cleaning and preparing the dataset
- Calculating key business KPIs
- Performing data analysis using Pivot Tables
- Building an interactive Power BI dashboard
- Identifying business insights from sales data

---

## 🛠️ Tools & Technologies

- Microsoft Excel
- Power BI Desktop

---

## 📂 Project Workflow

### 1. Data Cleaning (Excel)

- Removed duplicate records
- Handled missing values
- Corrected data formatting
- Prepared a clean dataset for analysis

### 2. KPI Calculations

The following KPIs were calculated:

- Total Sales
- Total Transactions
- Average Sales
- Total Quantity Sold
- Highest Transaction Value
- Lowest Transaction Value

### 3. Data Analysis

Performed analysis using Pivot Tables to answer business questions such as:

- Best performing product category
- Sales distribution by gender
- Quantity sold by product category
- Monthly sales trends

### 4. Power BI Dashboard

Created an interactive dashboard featuring:

- KPI Cards
- Product Category Sales Analysis
- Gender-wise Sales Distribution
- Quantity Sold by Category
- Monthly Sales Trend
- Interactive Slicers (Gender, Age Range, Category, Date)

---

✔ Interactive Filters

- Gender

✔ Visualizations

- Sales by Product Category
- Sales by Gender
- Quantity Sold by Product Category
- Monthly Sales Trend


## 💡 Key Insights

- Electronics generated the highest sales revenue.
- Clothing recorded the highest quantity sold.
- Sales were almost equally distributed between male and female customers.
- Monthly sales showed noticeable fluctuations throughout the year.
- Interactive filtering enables deeper business analysis across different customer segments.
