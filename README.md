# week-1-retail-sales-excel-analysis
📌 Overview

This project was completed as part of my Data Analytics Internship at LogicStack. The goal of this task was to clean a retail sales dataset, perform basic data analysis, create visualizations, and gain hands-on experience with Microsoft Excel.

🎯 Objectives
Understand the structure of the dataset.
Clean and format the data.
Perform data quality checks.
Apply Excel formulas for analysis.
Use sorting and filtering techniques.
Analyze sales by category and gender.
Create charts for data visualization.
Write data-driven observations.
🛠️ Tools Used
Microsoft Excel
📂 Project Tasks
Part 1: Dataset Understanding
Analyzed the dataset structure.
Identified the number of rows and columns.
Determined data types for each column.
Identified unique product categories.
Found the minimum and maximum customer ages.
Part 2: Data Cleaning & Formatting
Created a cleaned copy of the dataset.
Formatted the Date column.
Formatted Price per Unit and Total Amount.
Adjusted column widths.
Applied table formatting.
Froze the header row.
Part 3: Data Quality Check
Checked for blank cells.
Checked for duplicate records.
Validated Quantity values.
Validated Price per Unit values.
Verified that Total Amount = Quantity × Price per Unit.
Part 4: Basic Excel Formulas

Used Excel functions including:
SUM()
AVERAGE()

Calculated:

Total Sales
Average Sales
Minimum and Maximum Sales
Total Quantity Sold
Average Customer Age
Youngest and Oldest Customer
Total Transactions
Total Unique Product Categories
Part 5: Sorting & Filtering

Performed:

Highest and lowest sales analysis
Category-wise filtering
Gender-based filtering
Quantity-based filtering
Sorting by Total Amount
Sorting by Customer Age
Part 6: Category-Based Analysis

Created summary tables for:

Sales by Product Category
Quantity Sold by Product Category
Sales by Gender
Part 7: Charts

Created Excel charts to visualize:

Sales by Product Category
Quantity Sold by Product Category
Sales by Gender
Part 8: Observations

Recorded key insights based on the analysis.
